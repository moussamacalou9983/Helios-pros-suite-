# v1.0.0-scientific-core — Release Notes

**Date** : 2026-08-02
**Tag** : `v1.0.0-scientific-core`
**Portée** : moteur scientifique de position solaire HeliosPro
(`engine/`), et lui seul — aucune interface graphique, base de données,
API réseau, service web, IA ou génération de rapport n'est incluse dans
cette version.

## Résumé

Cette version fige officiellement le **socle scientifique** de HeliosPro :
calcul déterministe de la position solaire (SPA NREL complet + moteur
secondaire Meeus), irradiance extraterrestre et décomposition GHI/DNI/DHI,
transposition sur plan incliné (4 modèles), modèle thermique de cellule
(2 modèles), et l'orchestration de ces étapes jusqu'à la température de
cellule. Validée par une campagne de 2918 cas contre un oracle externe
indépendant sur l'enveloppe complète du produit, avec analyse
d'incertitude numérique quantifiée, tests de stabilité aux cas limites,
et couverture de tests de 97.99 %.

À partir de ce tag, **l'API publique du moteur de position solaire est
gelée** (voir `docs/design/19-politique-semver-api.md`) : aucune
modification de signature sans incrément de version documenté, et aucune
modification du moteur lui-même sauf correction de bug critique tant que
le développement se poursuit sur les modules suivants.

## Contenu livré

### Crates implémentés (9)

- `core_constants` — 13 constantes physiques/astronomiques référencées
  (CODATA, ISO, WGS84, Meeus).
- `core_units` — types forts SI : `Angle`, `Length`, `Pressure`, `Ratio`,
  `Temperature`, `Velocity`, `Irradiance`.
- `core_math` — Jour Julien (Meeus Ch. 7), interpolation linéaire,
  statistiques d'erreur (moyenne, biais, MAE, RMSE, écart-type,
  erreur relative).
- `solar_geometry` — temps solaire, angle d'incidence, moteur géocentrique
  SPA complet (Reda & Andreas 2004) et moteur géocentrique Meeus réduit
  (1998, secondaire).
- `solar_position` — position topocentrique sélectionnable (`Spa`/
  `MeeusReduced` via le trait `SolarPositionAlgorithm`), SPA par défaut.
- `irradiance` — irradiance extraterrestre (Spencer 1971), décomposition
  GHI→DNI/DHI (Erbs et al. 1982).
- `transposition` — 4 modèles de ciel : isotrope (Liu & Jordan 1963),
  Hay-Davies (1980), HDKR (Reindl et al. 1990), Perez (1990).
- `thermal_model` — NOCT (Ross 1976) et Sandia (King et al. 2004).
- `simulation` — orchestration position → irradiance POA → température
  de cellule.

### Crates outillage (2, jamais des dépendances du moteur de production)

- `validation` — comparaison automatisée contre pvlib-python (91 cas +
  campagne mondiale de 2918 cas).
- `tests` — tests de non-régression croisés (golden dataset), tests de
  stabilité numérique, benchmarks.

### Crates squelettes (3, aucune logique, prêts pour le prochain module)

- `pv_module`, `electrical_model`, `losses`.

## Points scientifiques marquants

- **SPA NREL complet** : implémentation intégrale de Reda & Andreas
  (2004) — séries héliocentriques VSOP87 tronquées (129+7+59 termes),
  nutation IAU 1980 (63 termes), obliquité Laskar (1986, degré 10),
  parallaxe topocentrique complète, réfraction atmosphérique. Précision
  contre pvlib-python : < 0.0002° sur l'échantillon de 91 cas, < 0.01° sur
  la campagne mondiale de 2918 cas.
- **Meeus (1998) conservé comme moteur secondaire** de validation croisée
  indépendante (série réduite, sans parallaxe) — jamais le moteur par
  défaut depuis la session 3.
- **Campagne de validation mondiale** : 2918 cas stratifiés couvrant
  latitude [-90°,90°], longitude [-180°,180°], altitude [0,6000] m,
  années 1900-2100, nuit/jour polaire, lever/coucher de soleil, zénith.
  Deux effets de bord réels (divergence de coupure de réfraction,
  singularité d'azimut au zénith) identifiés, expliqués et bornés par
  preuve plutôt que masqués.
- **Analyse d'incertitude numérique** : arrondi `f64` quantifié
  négligeable, expérience reproductible `f32` vs `f64`, sensibilité à ΔT
  chiffrée (facteur dominant hors fenêtre 2005-2050).
- **Stabilité numérique démontrée** : zéro NaN/instabilité, y compris aux
  pôles géographiques exacts, années 1582-9999, minuit UTC.
- **Performance** : SPA ~5.3-5.5 µs/appel, Meeus ~0.6-0.9 µs/appel, **zéro
  allocation sur le tas** en régime stable pour les deux moteurs.
- **Couverture de tests** : 97.99 % (lignes), mesurée avec
  `cargo-llvm-cov`, 164 tests, 0 échec.
- **Documentation** : 100 % de l'API publique documentée (vérifié
  mécaniquement), annexe technique publiable
  (`docs/design/18-annexe-technique-position-solaire.md`), bibliographie
  complète (`docs/references/`).

## Changements depuis la session précédente (SPA NREL, commit `274fc1a`)

Tous additifs ou correctifs de documentation, aucun changement cassant
(voir `docs/design/19-politique-semver-api.md` §19.5) :

- Ajout `solar_position::meeus::solar_position_precise` (delta_t
  explicite, pour la campagne mondiale hors fenêtre 2005-2050).
- Ajout `core_math::stats::standard_deviation`.
- Correction : `solar_position::spa` utilise désormais la constante
  nommée `core_constants::SOLAR_PARALLAX_ARCSEC_AT_1AU` au lieu d'un
  littéral dupliqué (valeur inchangée, aucun changement de comportement).
- Correction d'une erreur arithmétique dans la documentation de
  `solar_geometry::delta_t` (le commentaire sous-estimait d'un facteur
  ~60 l'effet d'une erreur de ΔT sur la position ; corrigé et complété
  par l'analyse quantitative de `17-analyse-incertitude-numerique.md`).

## Limites connues

Voir `docs/design/20-rapport-cloture-phase1.md` §6 pour la liste complète
(temps UTC uniquement, calendrier grégorien ≥1582, ΔT estimé valide
2005-2050 par défaut, nutation SPA tronquée à 63/106 termes, pas de
comparaison directe PVsyst/SAM/Archelios, irradiance/transposition/
thermique validés seulement par invariants internes, chaîne de simulation
s'arrêtant avant la puissance DC/AC).
